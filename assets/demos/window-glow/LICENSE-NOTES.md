# Window-glow demo asset

`photo.jpg` is the bundled photograph the launcher's "Try a demo"
button (003-T2.9) projects. It ships with rmap so a first-time
operator reaches "photo on a wall" without supplying their own asset.

## Status: PLACEHOLDER

The current `photo.jpg` is a 64 × 96 solid-colour JPEG generated by
`examples/gen_demo_photo.rs`. It is **not** the final asset — it
exists so the demo project file (`assets/demos/window-glow.rmap.json`)
loads cleanly through `ProjectAudit` and produces ≥ 1 visible pixel
through the render pipeline (003-T2.21 acceptance).

Replace this with the license-cleared photograph from spec-003 task
T0.2 before declaring M2:

- portrait orientation
- soft lighting
- ideally a single subject (a face, an object, or a window scene)
- license: CC0 from Unsplash, or original commissioned work, per
  decision D2 in `specs/003-tasks.md`
