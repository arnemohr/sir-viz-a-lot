# Golden test baselines

Existing baselines (`blur.png`, `color.png`, `warp.png`) are generated by
`tests/headless_gpu.rs` (run via `make test-gpu`). Rewrite them with
`UPDATE_GOLDEN=1 cargo nextest run --features gpu-tests`.
